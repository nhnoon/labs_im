Lab 1 - Jupyter Ready Folder
============================

1) Extract the ZIP file.
2) Keep the images folder next to Basics_Programming_Python.ipynb.
3) Double-click run_jupyter.bat, OR open Anaconda/Jupyter and browse to this folder.
4) Open Basics_Programming_Python.ipynb.
5) Use Kernel > Restart & Run All (or Run > Run All Cells).
6) Make sure all cells run without errors, then save the notebook.

If a package is missing, run install_requirements.bat once.

The NumPy exercise cells have been completed, and the two required images are included.
